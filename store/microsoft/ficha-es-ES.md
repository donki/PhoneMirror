## Nombre del producto

```
sOC Phone Mirror
```

## Descripción

```
sOC Phone Mirror enseña la pantalla de tu móvil Android en una ventana de Windows y te deja manejarlo
desde el PC: tocas con el ratón, escribes con el teclado y arrastras ficheros.

Conectas el móvil por USB, pulsas conectar y ya está. La ventana se adapta sola al móvil: si abres un
juego o un vídeo en apaisado, la ventana se pone apaisada con él.

QUÉ PUEDES HACER
• Tocar, deslizar y desplazar con el ratón; botón derecho para atrás y central para inicio.
• Escribir con el teclado del PC, con tu distribución de teclado.
• Copiar y pegar en los dos sentidos (Ctrl+C / Ctrl+V).
• Botones de atrás, inicio, recientes, notificaciones, apagar la pantalla, girar y volumen.
• Guardar una captura de la pantalla del móvil con un clic.
• Arrastrar un APK para instalarlo, o cualquier fichero para copiarlo al móvil.
• Abrir una ventana por móvil si tienes varios conectados.

NADA SALE DE TU PC
Todo pasa por el cable USB entre el PC y el móvil. No hay servidor, no hay cuenta, no sale nada a
internet. Sin anuncios, sin rastreadores y sin analítica.

QUÉ NECESITA
Un móvil o tablet Android (5.0 o superior) con la depuración USB activada, y las platform-tools de
Android (adb) en el PC. La aplicación las busca sola en los sitios habituales.

Software libre bajo licencia MIT. En español y en inglés, con modo claro y oscuro.
```

```
La pantalla del móvil en una ventana de Windows
Tocar, deslizar y escribir desde el PC
La ventana se adapta al móvil, también en apaisado
Portapapeles compartido en los dos sentidos
Atrás, inicio, recientes, notificaciones, pantalla, giro y volumen
Captura de pantalla con un clic
Arrastrar un APK para instalarlo o un fichero para copiarlo
Una ventana por cada móvil conectado
Todo por el cable USB: nada sale a internet
Software libre, en español y en inglés, claro y oscuro
```

cable USB entre el PC y el móvil; la aplicación no accede a internet.»
